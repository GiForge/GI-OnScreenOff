# 📱 Schermo Sempre Attivo

Mantieni il display acceso quando serve e spegnilo immediatamente con un solo tocco. L'app offre controlli rapidi, widget dedicati e funzioni di sicurezza per ridurre il consumo della batteria.

## ✨ Funzionalità Principali

### 🔆 Schermo Sempre Attivo
- Attivazione/disattivazione con un solo tocco.
- Indicatore visivo dello stato.
- Durate programmabili:
  - 5 minuti
  - 15 minuti
  - 30 minuti
  - 1 ora
  - Infinito
- Countdown integrato.

### ⚡ Spegnimento Immediato
- Pulsante rapido per spegnere e bloccare il display.
- Supporto tramite:
  - Accessibility Service
  - Device Administrator

### 🏠 Widget Home Screen
- Widget completo 2-in-1.
- Widget compatto 1x1.
- Controllo rapido direttamente dalla schermata
